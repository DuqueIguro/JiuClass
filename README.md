# JiuClass

## Visão Geral
O JiuClass é um projeto desenvolvido como parte da disciplina de LDS (Laboratório de Desenvolvimento de Software). Este sistema tem como objetivo auxiliar na gestão de academias de Jiu-Jitsu, oferecendo funcionalidades voltadas para o gerenciamento de salas, alunos, perfis e muito mais.

Este projeto é estruturado utilizando **PHP (60%)**, **CSS (25%)**, **JavaScript (6%)**, **HTML (4%)** e **Outros (4%)**.

## Funcionalidades
- Gerenciamento de salas e alunos.
- Criação de perfis personalizados.
- Banco de dados para armazenamento e gestão de informações.
- Layout totalmente responsivo e visualmente consistente.

## Estrutura do Projeto
- **Frontend:** HTML, CSS e JavaScript para a interface do usuário.
- **Backend:** Desenvolvido em PHP.
- **Banco de Dados:** Integração com MySQL para persistência de dados.
- **Scripts:** Scripts em JavaScript para funcionalidades dinâmicas.

## Histórico de Atualizações
O projeto segue uma nomenclatura de versões baseada em fases de desenvolvimento:
- **Alfa (α):** Desenvolvimento da interface e funcionalidades básicas.
- **Beta (β):** Implementação e integração de funcionalidades principais.
- **Delta (δ):** Testes e ajustes de funcionalidades.
- **Ômega (Ω):** Finalização, ajustes finos e preparação para entrega.

### Versão Atual: Beta (β-3.0.0)

## Instalação
1. Clone o repositório:
   ```bash
   git clone https://github.com/DuqueIguro/JiuClass.git
   ```
2. Configure o ambiente local com suporte a PHP e MySQL.
3. Importe o banco de dados disponível no diretório `/database`.
4. Inicie o servidor local e acesse o sistema pelo navegador.
